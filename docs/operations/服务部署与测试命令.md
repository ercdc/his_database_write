# HIS 数据病历填充服务：部署与测试命令

以下命令均在 PowerShell 中执行。

## 1. 进入项目目录

```powershell
cd "F:\艾赛思坦\首次病程SDK\his数据病历填充"
```

## 2. 本地启动服务

先在当前 PowerShell 会话设置 DeepSeek Key。不要把 Key 写入 `appsettings.json` 或提交到代码仓库。

```powershell
$env:DEEPSEEK_API_KEY = "你的 DeepSeek API Key"

dotnet run `
  --project .\src\HisMedicalRecordFillDemo\HisMedicalRecordFillDemo.csproj `
  --urls "http://127.0.0.1:5088"
```

看到以下日志表示服务已启动：

```text
Now listening on: http://127.0.0.1:5088
```

按 `Ctrl + C` 停止服务。

## 3. 调用接口

保持服务运行，并在另一个 PowerShell 窗口执行：

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri "http://127.0.0.1:5088/api/first-course/generate" `
  -ContentType "application/json" `
  -Body '{"patientId":"CASE-001","visitId":"TEST20260811001"}'
```

成功响应包含 `success`、`outputPath`、`message`。生成的 XML 位于：

```text
F:\艾赛思坦\首次病程SDK\his数据病历填充\Output\
```

查看最新 XML：

```powershell
$latest = Get-ChildItem .\Output\*.xml |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

Get-Content -Raw $latest.FullName
```

## 4. 自动测试

以下测试不调用真实 DeepSeek，不消耗模型额度：

```powershell
dotnet test .\HisMedicalRecordFillDemo.sln
```

## 5. 真实 DeepSeek 联调

以下命令会调用真实模型、生成 XML 并消耗 DeepSeek 额度：

```powershell
$env:DEEPSEEK_API_KEY = "你的 DeepSeek API Key"
$env:RUN_DEEPSEEK_INTEGRATION_TEST = "true"

dotnet test .\HisMedicalRecordFillDemo.sln `
  --filter "Category=Integration"
```

## 6. 发布服务

发布为 Windows x64 自包含版本：

```powershell
dotnet publish .\src\HisMedicalRecordFillDemo\HisMedicalRecordFillDemo.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -o .\publish
```

发布产物会输出到：

```text
F:\艾赛思坦\首次病程SDK\his数据病历填充\publish\
```

## 7. 运行发布后的服务

发布命令会将运行所需的 `Resources/` 与 `Fixtures/` 复制进发布目录，请保持它们与可执行文件在同一目录层级：

```text
部署目录/
└─ publish/
   ├─ HisMedicalRecordFillDemo.exe
   ├─ Resources/
   ├─ Fixtures/
   └─ Output/                 # 首次成功生成 XML 后自动创建
```

将整个 `publish` 目录复制到目标机器后，执行：

```powershell
cd "D:\HisMedicalRecordFillDemo\publish"

$env:DEEPSEEK_API_KEY = "你的 DeepSeek API Key"
$env:ASPNETCORE_URLS = "http://0.0.0.0:5088"

.\HisMedicalRecordFillDemo.exe
```

目标机器已安装 .NET 8 运行时且不需要自包含时，也可使用框架依赖发布：

```powershell
dotnet publish .\src\HisMedicalRecordFillDemo\HisMedicalRecordFillDemo.csproj `
  -c Release `
  -o .\publish
```

然后运行：

```powershell
dotnet .\HisMedicalRecordFillDemo.dll
```
